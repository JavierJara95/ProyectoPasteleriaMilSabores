# ProyectoPasteleriaMilSabores
Repositorio creado para caso semestral de Desarrollo Fullstack 2


## Correcciones EV1
- Validaciones JavaScript para registro, login y contacto.
- RUN chileno, dominios de correo, región/comuna dependiente.
- CRUD Front-End de productos y usuarios con localStorage.
- Carrito persistente, imágenes de productos y navegación corregida.
- Formularios administrativos ajustados a límites de la pauta.

## Usuarios de prueba

El proyecto inicializa automáticamente estos usuarios en `localStorage` si todavía no existen:

- Administrador: `admin@duoc.cl` / contraseña `Admin123` / RUN `111111111`
- Cliente: `cliente@gmail.com` / contraseña `Cliente12` / RUN `222222222`

El inicio de sesión valida correo y contraseña. El administrador es dirigido a `admin/home.html` y el cliente a la tienda pública.
